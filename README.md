# 🎯 วงล้อสุ่มชื่อนักเรียนในห้องเรียน (Classroom Wheel of Names)

เว็บแอปพลิเคชันสุ่มชื่อนักเรียนและรายชื่อสำหรับห้องเรียน **ไม่มีโฆษณา 100%** ดีไซน์โทนสว่าง ฟ้าสดใส พร้อม Font **Kanit** ตัวหนังสือขนาดใหญ่ อ่านง่าย มองเห็นชัดเจนบนหน้าจอ Smart TV และเครื่องฉายโปรเจกเตอร์

🌐 **เข้าใช้งานออนไลน์ได้ที่:** [https://wheelofname-blue.vercel.app/](https://wheelofname-blue.vercel.app/)

---

## ✨ จุดเด่นและฟีเจอร์หลัก (Features)

1. 🚫 **ไร้โฆษณา 100%**: ปลอดภัย สะอาด รวดเร็ว เหมาะสำหรับใช้ในการเรียนการสอน
2. 🎡 **วงล้อฟิสิกส์คมชัด (High-DPI Canvas Wheel)**: รองรับหน้าจอ 4K คมชัดทุกรายละเอียด
3. 🔊 **ระบบเสียงในตัว (Web Audio API)**: เสียงเข็มดีด (Tick Sound) และเสียงเฉลิมฉลอง (Victory Fanfare) โหลดไว ไม่ต้องพึ่งไฟล์ภายนอก
4. 🎊 **เอฟเฟกต์พลุกระดาษ (Confetti Animation)**: สร้างความตื่นเต้นเมื่อสุ่มได้ผู้ชนะ
5. 🏫 **จัดการห้องเรียนได้หลายห้อง**: บันทึกรายชื่อแยกห้อง (เช่น ม.1/1, ม.1/2) บันทึกลงเบราว์เซอร์อัตโนมัติ (LocalStorage)
6. 📋 **คัดลอก/วาง สะดวก**: วางรายชื่อจาก Excel / Google Sheets ได้ในครั้งเดียว
7. 🏆 **ระบบคัดกรองผู้ชนะ**: เลือกว่าจะ "เอาชื่อออก" (ไม่สุ่มซ้ำ) หรือ "คงชื่อไว้" พร้อมระบบดูประวัติผู้ที่ถูกสุ่มไปแล้ว
8. 📺 **โหมดเต็มหน้าจอ (Fullscreen)**: เหมาะสำหรับกดฉายขึ้นจอโปรเจกเตอร์หน้าห้อง
9. ⌨️ **คีย์ลัด (Shortcuts)**:
   - `Spacebar` : หมุนวงล้อ
   - `F` : เปิด/ปิด เต็มหน้าจอ
   - `M` : เปิด/ปิด เสียง

---

## 🚀 วิธีนำขึ้น Vercel (Step-by-Step)

1. เข้าเว็บไซต์ [vercel.com](https://vercel.com) แล้วเข้าสู่ระบบด้วย GitHub
2. กดปุ่ม **"Add New..."** -> เลือก **"Project"**
3. เลือก Repository `Wheelofname` ของท่าน
4. ในส่วน **Framework Preset** ให้เลือกเป็น **"Other"** (หรือปล่อยเป็น Default)
5. กดปุ่ม **"Deploy"**
6. ภายใน 10 วินาที ระบบจะสร้างลิงก์เว็บไซต์พร้อมใช้งาน เช่น `https://wheelofname.vercel.app` สามารถเปิดใช้ในห้องเรียนได้ทันที!
